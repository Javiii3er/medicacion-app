# Sistema Móvil de Medicación — PG2 2026

Aplicación móvil para el monitoreo, gestión y confirmación de medicación orientada a adultos mayores y sus cuidadores/familiares.

## 📁 Estructura del Repositorio

- `/app-movil`: Código fuente de la aplicación móvil en .NET MAUI.
- `/backend`: API REST y lógica de servidor en ASP.NET Core.
- `/docs`: Documentación del proyecto.
  - `/analisis`: Historias de usuario y requerimientos.
  - `/diseno`: Wireframes, diagramas y modelos de BD.
  - `/evidencias`: Capturas de pantalla y entregables de entorno.
  - `/manuales`: Manuales de usuario y despliegue.
  - `/pruebas`: Plan y casos de prueba.

## 🌿 Convención de Ramas

- `main`: Código estable y listo para producción / entrega final.
- `develop`: Rama principal de desarrollo donde se integran las funcionalidades.
- `feature/*`: Ramas secundarias para el desarrollo de funcionalidades específicas (ej. `feature/login`, `feature/alarmas`).

## 🛠️ Tecnologías
- **Frontend Móvil:** .NET MAUI (.NET 8/9)
- **Backend:** ASP.NET Core Web API
- **Base de Datos:** SQL Server / PostgreSQL
- **Gestión:** Trello & GitHub
